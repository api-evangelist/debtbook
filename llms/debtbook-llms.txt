# DebtBook

> DebtBook (a trademark of Fifth Asset, Inc.) is cloud-based treasury and accounting
> software for public finance teams — state and local government, K-12 and higher
> education, healthcare, and nonprofits. It covers debt management, cash management,
> investment management, contract management, and lease/subscription accounting under
> GASB 87, GASB 96 and ASC 842, with an AI layer (Insights, and the "Marty" analyst)
> over an organization's treasury data.

Generated by API Evangelist from public sources on 2026-08-04. DebtBook does not
publish an llms.txt of its own; https://www.debtbook.com/llms.txt returns 404.

## API surface

DebtBook publishes **no public API**: no developer portal, no API reference, no
OpenAPI/Swagger, no AsyncAPI, no GraphQL endpoint, no MCP server, and no A2A agent
card were found on any DebtBook host as of 2026-08-04. The "API" DebtBook refers to
publicly is an **inbound** integration — its Cash Management product reads real-time
bank account data through Koxa's Treasury Gateway open-banking platform (PNC, Regions
Bank, Bank of America, JPMorgan, Wells Fargo and other US banks). That integration is
governed by published terms, not by a self-service developer program.

- [Cash Management API integration terms](https://www.debtbook.com/cash-management-terms-api-integration): the contractual terms governing the Koxa-powered bank data integration
- [Status page](https://status.debtbook.com/): Atlassian Statuspage; the "Application" component is described as "Application and supporting APIs"
- [Status summary JSON](https://status.debtbook.com/api/v2/summary.json): machine-readable operational state

## Security and trust

- [Security overview](https://www.debtbook.com/security)
- [Trust center](https://trust.debtbook.com/): SOC 1 Type 1/2, SOC 2 Type 1/2, CSA STAR Level One; quarterly SOC bridge letters
- [Vulnerability disclosure program](https://www.debtbook.com/vdp): responsible disclosure, no bounty; scope `app.debtbook.com`, `sources.debtbook.com`, `uat.debtbook.com`; researchers must include `(db_vdp)` in the User-Agent; 5-business-day first response, 10-business-day triage; CFAA/DMCA safe harbor
- No `/.well-known/security.txt` is served (RFC 9116 gap — the VDP exists but is not machine-discoverable)
